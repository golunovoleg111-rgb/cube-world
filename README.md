# Cube World

Небольшая самостоятельная браузерная 3D-песочница, вдохновлённая воксельными играми. Собственный код и процедурная графика, без ресурсов Minecraft, библиотек, CDN, установки пакетов и серверной базы данных.

## Запуск

Нужен Node.js 20 или новее. `npm start` → http://127.0.0.1:4173. Также подойдёт любой статический HTTP-хостинг. Двойной щелчок по HTML не поддерживается из-за ES-модулей.

## Что есть

- Процедурный остров 64 × 64 × 28 блоков, деревья, берег, вода.
- Вид от первого лица, коллизии, прыжки и бег.
- Добыча и строительство, шесть бесконечных материалов.
- Поиск пяти кристаллов с сохранением прогресса.
- Автосохранение мира и позиции в localStorage каждые 4 секунды и при выходе в меню.
- Новая генерация с подтверждением, экономный режим графики.
- WebGL 1; объединённые сетки участков 16 × 16, удаление скрытых граней, локальное обновление геометрии и ограничение плотности пикселей.

## Управление

WASD / стрелки — движение; мышь — обзор; Пробел — прыжок; Shift — бег; ЛКМ / E — добыть; ПКМ / Q — поставить; 1–6 / колесо — блок; Esc / P — меню. Без захвата указателя можно зажать мышь и перетаскивать для обзора.

Первая версия предназначена для компьютера с клавиатурой, мышью и WebGL. Мобильное управление, крафт, мобы, мультиплеер и бесконечные миры пока не реализованы. Вода декоративная; погружения нет. Границы острова ограничивают движение. Сохранение привязано к браузеру и адресу сайта; очистка данных сайта удалит мир.

## Проверки

`npm test` — воспроизводимость генерации, доступность точки появления, кристаллы, коллизии, наведение и валидация сохранений. `npm run check` — проверка синтаксиса. Проверка браузером дополнительно нужна для WebGL, управления мышью и отображения.
