Новый мир

Мир создаётся по мере исследования. В выживании у тебя два пайка. Еду, блоки и инструменты взаимодействия используй на ПКМ.

Настройки

Твой выбранный профиль используется по умолчанию. Сглаживание MSAA работает при поддержке устройства; мир загружается участками.

Пауза

Выбери еду или путевой камень в руке и нажми ПКМ. ПКМ по двери открывает её, по сундуку — хранилище, по печи — плавку, по кровати — точку возрождения и сон ночью.

Рецепт в книге заполняет сетку 3×3. Нажми результат, чтобы создать предмет. В выживании ингредиенты расходуются. Рецепты печи: песок → стекло, руда → слиток, мясо → жареное мясо.

Без захвата мыши обзор работает перетаскиванием; R — добыча, Q — использование. Миры сохраняются в этом браузере.
