# Cube World · 0.3 — За горизонтом

**Играть:** https://golunovoleg111-rgb.github.io/cube-world/

Самостоятельная браузерная воксельная песочница с оригинальным WebGL-движком. Без библиотек, CDN и сторонних игровых ресурсов.

## Большой процедурный мир

Новые миры по умолчанию используют `continental-v1`: луга, леса, пустыни, снежные горы, каньоны, пещеры, подземные кристаллы и уголь. Рельеф привязан к зерну и координатам, включая отрицательные: порядок загрузки не влияет на результат. Высота — 96 блоков; горизонтальные координаты поддерживаются до ±1 000 000. Это расширяемый мир, а не заранее созданный большой массив.

Генерация участков 16×16 работает в Web Worker. Вокруг игрока постепенно строится сетка 7×7 участков; дальние данные и GPU-буферы выгружаются. Изменённые блоки сохраняются отдельно и возвращаются при повторном посещении. Меши используют локальные координаты для точности далеко от начала мира. Если Worker недоступен, используется последовательная генерация в основном потоке. Первая загрузка и быстрое исследование могут сопровождаться появлением рельефа у горизонта.

Старые миры 0.1/0.2 сохраняют исходный остров и постройки. При создании можно также выбрать классический остров. Для новых биомов нужно создать новый большой мир — старый рельеф намеренно не заменяется.

## Свет и выживание

- Цикл дня и ночи длится 15 минут игрового времени, часы останавливаются на паузе. Меняются цвет неба и яркость поверхности; видны кубические солнце и луна.
- Подземные поверхности темнее; факелы и кристаллы дают локальный свет. Уголь + дерево → четыре факела. Факел светит в руке и после установки. В кадре используются четыре ближайших источника.
- Здоровье, расход сытости, ускоренный расход при беге, восстановление здоровья при высокой сытости, урон при голодании, падении и нехватке воздуха. При голодании здоровье не опускается ниже 1; другие опасности могут убить. Два стартовых пайка дают время на исследование.
- Овцы и олени бродят по суше, убегают при ударе и дают еду после гибели. Ночные существа преследуют игрока и атакуют вблизи при отсутствии стены. Днём они получают урон от света. В творчестве они не атакуют.
- Восемь быстрых слотов настраиваются нажатием на любой материал в инвентаре. Добавлены снег, терракота, уголь и факелы.
- Путевой камень помогает записать координаты базы и узнать расстояние до неё.

## Настройки и управление

Стандартный профиль по просьбе пользователя: FOV 75°, чувствительность 2.5, без инверсии, текстуры 32×32, MSAA при поддержке GPU + 150% разрешения. Более низкие варианты текстур и разрешения убраны. Старый графический профиль однократно заменяется новым, затем настройки мыши и FOV сохраняются.

| Клавиша | Действие |
| --- | --- |
| WASD / стрелки | Движение |
| Мышь | Обзор |
| Пробел / Shift | Прыжок / бег |
| ЛКМ / R | Добыча / атака |
| ПКМ / Q | Строительство |
| 1–8 / колесо | Быстрый слот |
| E / I | Инвентарь, рецепты, еда |
| C | Поесть |
| B / Shift+B | Путевой камень / перенести |
| F | Полёт в творчестве |
| Пробел / Shift в полёте | Вверх / вниз |
| Esc / P | Главное меню и пауза |

В инвентаре творчества доступно переключение дня и ночи. Без захвата указателя обзор работает перетаскиванием с зажатой мышью; R и Q выполняют действия.

## Запуск и проверка

Node.js 20+: `node server.mjs` → http://127.0.0.1:4173/ . Можно использовать любой статический HTTP-хостинг. Сборки и установки пакетов нет. GitHub Pages публикует корень `main`.

`npm test` — 23 проверки: камера и прицел, генерация всех биомов, пещеры, границы участков, повторная загрузка построек, сохранения старых и новых миров, инвентарь, еда, голод, цикл освещения, прицеливание по мобам, крафт факелов, точность мешей на больших координатах. `npm run check` проверяет синтаксис.

## Текущие пределы

Игра для компьютера с клавиатурой, мышью и WebGL. Это собственная развивающаяся песочница; полного набора механик Minecraft пока нет. Освещение приближённое: без shadow maps, трассировки лучей и физического распространения света. Вода не течёт. У мобов простое поведение с обходом небольших препятствий, без сложного поиска пути. Одновременно активно до 24 существ. Это не симуляция удалённых регионов: существа вдали выгружаются, состояние ближайших и список побеждённых сохраняются.

Миры находятся в localStorage текущего браузера и адреса. Сохраняются только правки, инвентарь, время и состояние персонажа, а не весь сгенерированный ландшафт. Очистка данных сайта удаляет сохранения. Объём больших построек ограничен квотой браузера; при ошибке показывается уведомление и блокируется переключение мира. Мультиплеера и синхронизации устройств пока нет.
