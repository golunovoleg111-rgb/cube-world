# Cube World · 0.2

Самостоятельная браузерная воксельная песочница. Оригинальный движок WebGL и процедурные текстуры; без ресурсов Minecraft, CDN и зависимостей.

**Играть:** https://golunovoleg111-rgb.github.io/cube-world/

## Что изменилось в 0.2

- Исправлен знак наклона камеры: движение мыши вверх поднимает взгляд. Инверсия включается отдельно.
- Луч добычи совпадает с центром камеры при любом угле обзора. Точный обход вокселей DDA выбирает ближайший блок и соседнюю грань для строительства. При клике цель пересчитывается заново.
- Оригинальный атлас текстур 16×16 или 32×32: трава, земля, камень, кора, спил, листья, песок, кристалл, вода, доски, кирпич.
- Исправлен туман на воде; есть полупрозрачная поверхность, движущаяся рябь и плавание.
- Аппаратное сглаживание MSAA при поддержке устройства, дополнительное разрешение 125%/150% по настройке.
- Главное меню: список миров, создание, название, зерно, выбор режима, удаление с подтверждением. Настройки мыши, инверсии, FOV, детализации и разрешения.
- Инвентарь, восемь материалов, быстрые слоты, создание досок из дерева и кирпича из камня.
- **Творчество:** бесконечные блоки, отсутствие урона, переключаемый полёт.
- **Выживание:** пустой стартовый инвентарь, добыча ресурсов, расход материалов, 20 единиц здоровья, урон от падения и нехватки воздуха под водой. После гибели игрок возвращается в центр с сохранением материалов.
- Независимое автосохранение каждого мира. Старое сохранение 0.1 однократно переносится в творческий мир «Мой первый остров», исходные данные сохраняются.

## Управление

| Клавиша | Действие |
| --- | --- |
| WASD / стрелки | Движение |
| Мышь | Обзор |
| Пробел / Shift | Прыжок / бег |
| ЛКМ / R | Добыча |
| ПКМ / Q | Строительство |
| 1–8 / колесо | Выбор блока |
| E / I | Инвентарь |
| F | Полёт в творчестве |
| Пробел / Shift в полёте | Вверх / вниз |
| Esc / P | Главное меню и пауза |

Без захвата указателя для обзора нужно зажать мышь и перетаскивать; для добычи и строительства доступны R и Q.

## Запуск и проверки

Нужен Node.js 20+. Зависимостей нет: `node server.mjs` → http://127.0.0.1:4173/ . Можно использовать любой статический HTTP-хостинг. Через file:// ES-модули не запускаются.

`npm test` — 11 проверок, включая регрессию камеры по выражениям из настоящего GPU-шейдера, точный выбор блоков, генерацию, сохранения и миграцию, крафт, проверку данных и текстуры. `npm run check` — синтаксис модулей.

На GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root). Сборка не требуется.

## Технические ограничения

Остров 64×64×28, объединение видимых граней в участки 16×16, локальное обновление геометрии после строительства. Это конечный мир для компьютеров с клавиатурой, мышью и WebGL. Пока нет мобов, голода, инструментов, сложного верстака, мультиплеера и управления касанием. Вода — поверхность с плаванием и проверкой воздуха, без течения и симуляции жидкостей. MSAA зависит от браузера и GPU.

Миры и настройки находятся в localStorage текущего браузера и адреса сайта. Очистка данных сайта удаляет их; синхронизации между устройствами нет. Если сохранение не удалось, показывается сообщение, а переключение мира блокируется, чтобы не потерять изменения.
